# BullySkate v0.1.0

[Download BullySkate](https://github.com/Faiqie/BullySkate/releases/download/v0.1.0/BullySkate-Windows-v0.1.0.zip)

Extract the ZIP and open **BullySkateLauncher.exe**. Pick your **Bully.exe** and Skate 3 **default.xex** in the file-selection windows. The launcher handles setup and starts the game. Use the same launcher next time.

**Requires Bully Scholarship Edition for Windows, version 1.200, and your own complete extracted Xbox 360 Skate 3 files. Neither game is included.** Steam users should select the installed game and keep Steam signed in.

- Skate as Jimmy with his original skateboard and controller support.
- Edit stance, trucks, wheels, gestures, style and posture.
- Adjust skating FOV, set markers and respawn.
- Strike pedestrians with your board and skitch behind cars.
- Updated Steam setup and display-scaling correction.

**F6:** Skate · **F5:** Native Bully · **F8:** Edit Skater / FOV
